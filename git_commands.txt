
**Git Commands to learn basic to advance in real time DevOps workspace.**

1.  git status    # to see the status of the commit
2.  git add .\testting.py   # we adding the testing.py untracked to stagging area                                                                                                                                                                                                                                                                                                
3.  rm --cached .\testting.py    # remvoing the testing.py file from local machine or in git                                                                                                                                                                                                                                                                                                      
4.  git add .\testting.py                                                                                                                                                       
5.  git commit -m "added testing files"    # It is used to save the changes in to local repository with a short message that describe the changes.                                                                                                                                  
6.  rm .\testting.py     #  Its removing the testing file for the local repository.                                                                                                                                     
7.  git restore testting.py      # restroing the testing.py file again when someone has deleted the file accidentally we can restore the file in git                                                                                                                                           
8.  git pull  # its downloads the latest changes from the remote repository and updates the local repository.
9.  git push # we have the file in local and i need to push the changes into remote repository
10. git remote -v   # to see the remote repository added or not 
11. git remote set-url origin https:// paste token here@github.com/sanju-1625/github-for-devops # Access the github repository creating a token to setup the url.
