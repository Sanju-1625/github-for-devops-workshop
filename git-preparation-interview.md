# Q2: Why do companies use Git?
Companies use Git because multiple developers work on the same project. Git helps us track every change made to the code and maintain the complete version history. We can identify who made the changes and when they were made. If something goes wrong, we can easily roll back to a previous version. Git also makes collaboration easier by allowing developers to work on different branches and merge their code safely
