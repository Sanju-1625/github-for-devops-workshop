# Git Installation

## Objective

Learn how to install Git and verify the installation.

---

## Prerequisites

- Windows Operating System
- Internet Connection
- Administrator Access

---

## Step 1: Download Git

Open your browser.

Go to:

https://git-scm.com/downloads

Download Git for Windows.

---

## Step 2: Install Git

Double-click the downloaded installer.

Keep all default options.

Click Next until the installation is completed.

Click Finish.

---

## Step 3: Verify Installation

Open Command Prompt, PowerShell or Git Bash.

Run

```bash
git --version
```

Expected Output

```text
git version 2.xx.x.windows.x
```

---

## Step 4: Open Git Bash

Right Click

Open Git Bash Here

Verify

```bash
pwd
```

Expected Output

```text
/your/current/path
```

---

## Step 5: Verify Git

Run

```bash
git --help
```

Expected Output

Git help page should open.

---

## Commands Summary

```bash
git --version

git --help

pwd
```
