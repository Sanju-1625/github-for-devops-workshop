# Git Introduction

## Objective

Learn what Git is and why it is used.

---

## Prerequisites

- Basic computer knowledge
- Terminal installed

---

## What is Git?

Git is a Distributed Version Control System (DVCS).

It helps developers track code changes and manage source code.

---

## Why do we use Git?

- Track changes
- Maintain version history
- Work with multiple developers
- Roll back to previous versions
- Manage source code

---

## Real-Time Example

Three developers work on the same project.

Developer 1 -> Login Feature

Developer 2 -> Payment Feature

Developer 3 -> Dashboard Feature

Git helps everyone work together without overwriting each other's code.

---
